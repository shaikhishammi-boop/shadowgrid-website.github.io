About Shammi Alam Shaikh

Network Engineer | ICT Security & Infrastructure | Cisco CCNA | Cloud & VPN Solutions

I am a network engineer with hands-on experience in designing, implementing and securing enterprise ICT infrastructure. I am part of the Application & Design Unit at Main Hardware International Japan Inc., where I work on network infrastructure design, SOC security operations and Cloud Link environment troubleshooting.

My core expertise includes Cisco switch configuration, VLAN management, IP networking and network security, combined with a growing focus on AWS and cloud security. I recently used AutoCAD to design ICT network infrastructure layouts for an infrastructure migration project, strengthening TCP/IP connectivity and power distribution planning across the deployment.

I hold a Master's in Computer Applications from Techno India University and I am based in Tokyo. I am building my Japanese language skills (JLPT N2 aspirant) alongside my technical work, which brings a global, cross-cultural perspective to infrastructure and security.

Currently exploring

  • AWS security
  • Cloud and VPN solutions
  • Advanced network automation

I am open to connecting with fellow network engineers, ICT professionals and anyone working where infrastructure and security meet.
